ботами-помощниками, волнами врагов по ночам и управляемым дроном.

**Unity 6000.3.19f1 · URP · Input Manager (legacy) · Unity Behavior · UI Toolkit (переход с uGUI)**

## Главные ограничения

1. **Не менять игровое управление без явной просьбы.** Логика полёта дрона и
   управление игроком настроены вручную «на ощупь»; правка «как лучше» ломает
   ощущение игры. Подробнее: [Дрон](Docs/drone.md#правило-не-переписывать-управление).
2. **Проверять компиляцию до заявления о готовности** —
   [как именно](Docs/conventions.md#проверка-изменений).
3. **Не хранить изменяемое состояние в ScriptableObject** — это уже источник
   нескольких багов, см. [Известные проблемы](Docs/known-issues.md#p1-3-состояние-игры-живёт-в-ассетах).
4. **Пушить прямо в `main`**, без веток и PR.

## Сборка и проверка

Unity открыт на этой папке; MCP-сервер `UnityMCP` подключён, поэтому консоль,
сцену и play mode можно читать прямо из агента. Компиляцию отдельных скриптов
можно проверять Roslyn'ом без Unity — рецепт в
[Соглашениях](Docs/conventions.md#проверка-изменений).
