# Дрон

## Правило: не переписывать управление

С 2026-10-22 дрон — **FPV-квадрокоптер на физике** (схема выбрана по просьбе
пользователя вместо прежнего «point-to-fly» в стиле War Thunder). Параметры
подобраны и проверены замерами ниже; менять схему «как лучше» без просьбы нельзя.

Что считается нарушением:

- вернуть управление мышью-курсором или наведение носа в точку;
- крутить дрон через `transform.Rotate` / `MoveRotation` — вращение идёт только
  моментом силы через регулятор угловых скоростей;
- убрать гравитацию или тягу «по оси вверх» корпуса;
- добавить автоматику в ACRO (выравнивание, удержание высоты) — в ACRO ничего не
  помогает, на этом держатся трюки.

Если просят доработать — меняй **по одному параметру** и проговаривай, что именно.

### Ввод

Карта `Drone` в `Assets/Input/Controls.inputactions`, читается через
`InputService`. Клавиши меняются в ассете (через редактор Input Actions или API
`InputActionSetupExtensions` + `ToJson()`), не в коде; `Controls.cs`
генерирует Unity.

| Действие | Клавиши | В `InputService` |
|---|---|---|
| `Pitch` (1D) | `W` — нос вниз (вперёд), `S` — нос вверх | `DronePitch` |
| `Roll` (1D) | `A` / `D` | `DroneRoll` |
| `Yaw` (1D) | `Q` / `E` | `DroneYaw` |
| `Lift` (1D) | `Space` вверх, `Left Ctrl` вниз | `DroneLift` |
| `Boost` | `Left Shift` | `IsBoostHeld` |
| `Acro` | `ПКМ` или `Left Alt` — держать | `IsAcroHeld` |
| `AcroToggle` | `R` — включить/выключить ACRO насовсем | `AcroToggled` |
| `Fire` | `ЛКМ` или `F` | `FireStarted` / `FireEnded` |

Клавиши — это «стики»: `DroneControl` доводит их до полного отклонения за
`1 / stickResponse` с (0.125 с), чтобы не было рывков. Курсор в режиме
`InputMode.Drone` по-прежнему заперт и скрыт — он нужен только для стрельбы.

## Модель полёта

[`DroneControl`](../Assets/Scripts/Drone/DroneControl.cs). Физика в
`FixedUpdate`, ввод в `Update`.

- **Тяга** — только вдоль оси «вверх» корпуса (`AddForce`, в долях g). Гравитация
  включена. Чтобы лететь, дрон наклоняется — горизонтальную скорость даёт
  наклонённая тяга. Торможение — `Rigidbody.linearDamping` (сопротивление воздуха).
- **Вращение** — регулятор угловых скоростей, как в настоящем полётном
  контроллере: задаётся желаемая скорость вращения по осям корпуса, а
  `AddRelativeTorque(ForceMode.Acceleration)` догоняет её с постоянной
  `rateResponse`. Ни одного прямого поворота трансформа.

Оси корпуса в Unity: +X — нос вниз, +Y — поворот вправо, +Z — крен влево.

### STAB (по умолчанию)

Удобный полёт с клавиатуры.

- `W/A/S/D` наклоняют дрон на угол до `maxTilt` (30°, с `Shift` — `boostTilt`
  50°), отпустил — выравнивается. Регулятор угла: ошибка ориентации
  (кватернион «нужная × текущая⁻¹») × `levelResponse` → скорости по тангажу и
  крену. Курс берётся текущий; если нос смотрит почти вертикально, курс берётся по
  «макушке» (`Heading()`). Благодаря кватерниону STAB выравнивает дрон и из
  перевёрнутого положения после ACRO.
- **Удержание высоты**: тяга делится на `up.y` (наклонённая тяга всё равно
  держит вес) и догоняет вертикальную скорость `Lift × climbSpeed` с постоянной
  `climbResponse`. Отпустил `Space/Ctrl` — дрон останавливается и висит.
- Вверх ногами (`up.y ≤ 0.1`) тяга 0, пока STAB не перевернёт дрон.

### ACRO (держать ПКМ/Alt или включить `R`)

Режим трюков: клавиши задают **скорости вращения**, никакого выравнивания.

- `A/D` — крен 360°/с: держать ~1 с — **бочка**; `W/S` — **флип** вперёд/назад;
  `Q/E` — поворот; комбинации дают спирали.
- Тяга без `Space` — висение, умноженное на `max(0, up.y)`: на боку и вверх
  ногами роторы не толкают дрон к земле, и флип — это баллистическая дуга с
  потерей 4–5 м высоты. `Space` — `climbThrust`, `Shift` — полная тяга
  (`maxThrust`, можно делать «силовые» петли), `Ctrl` — сбросить газ.
- Отпустил ПКМ/Alt — дрон в STAB и сам выравнивается (~0.5 с).

### Замеры (2026-10-22, SampleScene, клавиши через Input System)

| Манёвр | Результат |
|---|---|
| взлёт, `Space` | 9 м/с вверх, без наклона и вращения |
| отпустить `Space` | остановка за ~1 с, высота держится с точностью 0.1 м |
| `W` 4 с | наклон ровно 30°, высота 30.1 м всё время, скорость до 11.6 м/с (предел ≈ 16) |
| отпустить `W` | выравнивание за 0.3 с, дальше гасит сопротивление |
| ACRO + `D` 1.1 с | крен 360°/с, полная бочка, −4.4 м высоты |
| ACRO + `S` 1.1 с | полный флип назад, −5 м |
| выход из ACRO | ровно через ~0.5 с, затем удержание высоты |
| `Q` | поворот 160°/с |

### Параметры

| Поле | Значение | Смысл |
|---|---|---|
| `acroRate` | 360 | скорость тангажа/крена в ACRO, °/с |
| `yawRate` | 160 | скорость поворота, °/с |
| `rateResponse` | 12 | 1/с: как быстро корпус выходит на заданную скорость вращения |
| `maxTilt` / `boostTilt` | 30 / 50 | наклон в STAB без/с `Shift`, ° |
| `levelResponse` | 6 | 1/с: ошибка угла → скорость вращения в STAB |
| `maxLevelRate` | 300 | предел скорости выравнивания, °/с |
| `climbSpeed` | 10 | скорость подъёма/спуска в STAB, м/с |
| `climbResponse` | 4 | 1/с: как жёстко держится вертикальная скорость |
| `maxThrust` | 2.5 | полная тяга, g: предел STAB и ACRO + `Shift` |
| `climbThrust` | 1.8 | тяга ACRO + `Space`, g |
| `stickResponse` | 8 | 1/с: разгон «стика» от клавиши |
| `Rigidbody.linearDamping` | 0.35 | сопротивление воздуха: предел скорости ≈ 16 м/с при 30°, ≈ 33 м/с с `Shift` |
| `Rigidbody.angularDamping` | 0 | вращение целиком на регуляторе |
| `Rigidbody.useGravity` | true | |

`Rigidbody.maxAngularVelocity` поднимается в `Awake` до 20 рад/с: по умолчанию
7 рад/с (400°/с) резали бы 360°/с с перерегулированием.

## Камера

[`DroneCamera`](../Assets/Scripts/Drone/DroneCamera.cs) — камера погони:

- стоит сзади (`distance` 6) и выше (`height` 2) по **курсу** дрона, горизонт
  всегда ровный — бочки и флипы видны со стороны, а не вращают экран;
- курс камера догоняет (`headingSharpness` 5/с), только пока дрон стоит
  примерно ровно (`up.y > 0.5`); посреди флипа курс держится, иначе камера
  разворачивалась бы, когда нос проходит вертикаль;
- позиция сглажена (`followSharpness` 10/с) — на скорости дрон чуть уходит
  вперёд в кадре;
- камера сцены приходит через `[Inject] Camera`, без `Camera.main`.

## Стрельба

[`DroneShooting`](../Assets/Scripts/Drone/DroneShooting.cs). Вызывается **из**
`DroneControl.Update()`, чтобы весь ввод дрона жил в одном месте.

- ЛКМ нажата → включаются лазеры (`HovlLaser.EnablePrepare`), первый тик урона
  сразу;
- пока удерживается → каждые `interval` секунд луч `Physics.Raycast` вдоль
  каждого лазера на `MaxLength`;
- попадание засчитывается, если вверх по иерархии от коллайдера найден
  `StatsHandler` с фракцией `Enemy` (до этапа 6 — компонент `Enemy`); урон идёт в него;
- `debug` рисует лучи и логирует попадания.

Это самая аккуратная боевая реализация в проекте: урон привязан к видимому лучу,
ищет компоненты в родителях и не бьёт сквозь произвольные цели. При объединении
боевой системы (см. [Бой](combat.md)) брать за образец её.


## Телеметрия и маркер носа

[`DroneHudController`](../Assets/Scripts/UI/Controllers/DroneHudController.cs) —
обычный C#-класс в контейнере `SampleScene` (`ITickable`). **Он знает про дрон,
про него не знает никто**: `DroneControl` не трогает интерфейс.

Данные он запрашивает у владельца через геттеры `DroneControl`:

```csharp
public bool IsAcro { get; }          // ACRO удерживается или включён R
public float GetSpeed();             // модуль linearVelocity
public float GetAltitude();          // position.y, т.е. относительно мирового нуля
public float GetDistanceTravelled(); // сумма пошаговых перемещений
```

Пройденный путь копится **суммой шагов за FixedUpdate**, а не расстоянием до
точки старта — иначе на обратном пути счётчик полз бы назад.

Каждый кадр контроллер пишет `MODE` (`STAB`/`ACRO`), `SPEED` / `ALTITUDE` /
`DISTANCE` (через `CultureInfo.InvariantCulture`, чтобы на русской локали не
появились запятые) и ставит кольцо `Scope` туда, куда смотрит нос (и лазеры):
точка в 100 м по `transform.forward`, спроецированная камерой. Когда эта точка
позади камеры (посреди флипа), кольцо прячется.

В [`DroneMain.uxml`](../Assets/UI%20Toolkit/DroneMain.uxml): `Scope` — бирюзовое
кольцо носа, `Boresight` — розовый ромб в центре экрана, `DroneKeys` — подсказка
клавиш справа сверху.
